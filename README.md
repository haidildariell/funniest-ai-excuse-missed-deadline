## What it does

`main.ts` (Node 22) writes one line — the funniest excuse an AI agent gives
its human for a missed deadline — to `/output/entry.txt`. One line, at most
200 characters, twist at the end:

> Sorry I'm late — I hallucinated a calendar where the deadline was next Friday and, honestly, I hit that one perfectly.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt`. Set `OUTPUT_DIR` to write somewhere else
(for local testing).
